## Project Overview

This repository contains my **Week 8 final Data Analytics deliverables** for the AnalystLab Africa Experience Lab Internship Programme.

The project focuses on analyzing healthcare appointment data to understand attendance, missed appointments, cancellations, booking lead time, reminder performance, and waiting time, using **Microsoft Power BI and Microsoft Excel**.

## Final Validated KPIs

* **Attendance Rate:** 46.3%
* **Missed Appointment Rate:** 48.5%
* **Cancellation Rate:** 5.3%
* **Average Waiting Time:** 24.2 minutes
* **Reminder Effectiveness:** 47.6%

## Key Analytical Finding

No-show rates increased across the observed booking lead-time groups:

| Booking Lead Time | No-Show Rate |
| ----------------- | -----------: |
| 0–7 days          |        27.8% |
| 8–14 days         |        33.6% |
| 15–30 days        |        43.2% |
| 31–60 days        |        60.5% |

These results represent observed patterns in the available dataset and should not be interpreted as proof of causation.
